Given a list of Inspector CVE findings for the same EC2 instance, produce one shell command that patches all vulnerable packages.

Findings:
{{findings}}

Respond with ONLY a JSON object (no markdown):
{
  "action": "PATCH" or "SKIP",
  "command": "the exact shell command to run",
  "reason": "one-line explanation"
}

Rules:
- Combine all packages into one command. E.g.: `dnf update pkg1 pkg2 pkg3 --releasever latest -y`
- Amazon Linux 2023: `dnf update <pkg1> <pkg2> ... --releasever latest -y`
- Amazon Linux 2: `yum update <pkg1> <pkg2> ... -y`
- Ubuntu/Debian: `apt-get update && apt-get install --only-upgrade <pkg1> <pkg2> ... -y`
- For ALAS advisories: `dnf update --advisory <id1> --advisory <id2> ... --releasever latest -y`
- Extract package names from Title fields (usually "CVE-XXXX-XXXXX - <package>") and VulnerablePackages fields.
- Use one update command covering all packages, not separate ones per CVE.
- If you can't determine the packages or OS, set action to "SKIP".
- Never remove packages, reboot, or change system config.
